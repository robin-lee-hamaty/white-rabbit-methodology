# 🐇 The White Rabbit Methodology

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22068233.svg)](https://doi.org/10.5281/zenodo.22068233)

### The Ethical Hacker's Operator's Handbook

> **KNOW IT · BUILD IT · BREAK IT · DETECT IT · FIX IT · PROVE IT**

The **White Rabbit Methodology** is an independent cybersecurity practitioner methodology developed by **Robin Lee Hamaty**.

It approaches offensive and defensive security as complementary views of the same system.

The objective is not simply to exploit a weakness.

The practitioner should understand **why the weakness exists**, reproduce the environment, demonstrate the weakness under authorization, identify the evidence generated by the activity, engineer or recommend the appropriate defensive control, and then retest the system to prove that the remediation works.

---

## 🐇 The White Rabbit Loop

### 1. KNOW IT

Understand the technology, architecture, protocols, dependencies, and trust boundaries.

### 2. BUILD IT

Reproduce the system so that its assumptions and behavior become visible.

### 3. BREAK IT

Test those assumptions in an owned laboratory or explicitly authorized environment.

### 4. DETECT IT

Identify the logs, packets, events, artifacts, and behaviors generated by the attack.

### 5. FIX IT

Engineer or recommend controls that address the underlying weakness.

### 6. PROVE IT

Repeat the test and demonstrate that the remediation actually works.

---

## 🛡️ Offensive + Defensive Security

The White Rabbit Methodology treats exploitation as the beginning of understanding rather than the end of an assessment.

A technically successful exploit demonstrates a weakness.

An exploit that can also be **explained, observed, detected, mitigated, retested, and documented** becomes operationally useful.

> **Red skill proves the weakness.**  
> **Blue visibility makes it defensible.**  
> **Purple understanding turns the lesson into protection.**

---

## 🎯 MITRE ATT&CK

**MITRE ATT&CK** forms a foundational framework throughout the White Rabbit Methodology.

ATT&CK provides a common language for connecting adversary behavior with offensive execution, defensive visibility, detection engineering, mitigation, and validation.

The objective is not simply to memorize technique identifiers. It is to understand:

- how the behavior works;
- why it works;
- what evidence it generates;
- how defenders can observe it;
- how it can be detected or disrupted; and
- how remediation can be validated.

## ⚠️ Responsible Use

The White Rabbit Methodology is intended for cybersecurity education, professional development, defensive research, and **authorized security testing**.

Offensive techniques and laboratory exercises should be performed only against systems owned by the practitioner or systems for which explicit authorization to test has been granted.

Nothing in this repository should be interpreted as authorization to test, access, interfere with, or modify systems without the explicit permission of their owner.
